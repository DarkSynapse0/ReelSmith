# samples/

Put test videos here to experiment with. This folder is a handy place to
keep a short clip or two while you try out settings.

Video files in this folder are **ignored by git** (see `.gitignore`) so you
don't accidentally commit large media. Only this README is tracked.

Example:

```bash
# drop a file here, then:
videoclipper samples/my_test.mp4 --language en --clips 3
```
